# Botiquín de Cariño (Android nativo)

Esta versión no usa HTML/WebView: está portada a Android nativo con Kotlin + Material.

## Qué incluye

- Pantalla principal con tarjetas en grilla.
- Modal tipo Bottom Sheet con detalle del remedio.
- Herramientas nativas integradas:
  - respiración guiada,
  - afirmaciones aleatorias,
  - frasco de gratitud con chips editables.

## Stack técnico

- Kotlin (JVM target 17)
- Android SDK (minSdk 24)
- Material Components
- RecyclerView

## Ejecutar

1. Abre el proyecto en Android Studio.
2. Sincroniza Gradle.
3. Ejecuta en emulador o dispositivo.
