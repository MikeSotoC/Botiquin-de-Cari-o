# Botiquín de Cariño (Android nativo)

Esta versión ya **no usa HTML/WebView**. La experiencia fue portada a UI nativa Android con Java.

## Qué incluye

- Pantalla principal con tarjetas (cards) en grilla.
- Modal tipo Bottom Sheet con detalle del remedio.
- Herramientas nativas integradas según tarjeta:
  - respiración guiada,
  - afirmaciones aleatorias,
  - frasco de gratitud con chips editables.

## Stack técnico

- Java 17
- Android SDK (minSdk 24)
- Material Components
- RecyclerView

## Ejecutar

1. Abre el proyecto en Android Studio.
2. Sincroniza Gradle.
3. Ejecuta en emulador o dispositivo.
